# The World Today — 24 November 2026

A newspaper front page in one image summing up the world news of Tuesday 24 November 2026: Jensen Huang's Trump-backed return to Nvidia and the record market rally it sparked, allied warnings of a Russian nuclear space weapon, Ukraine's sinking of a Russian warship off Libya, Sheikh Hasina's planned return to Bangladesh, and U.S. states suing Elon Musk's firms over Grok images.
